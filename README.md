# Project Title 

My project title is “Exploring the Constellations”  
 
## Project Option 
It is an interactive educational website. 
  
 
## Project Description 
The website displays information about some of the most common constellations in the night sky that can be viewed.  They are separated by the season of the year.  Each season includes 3 constellations that when clicked on a pop-up box will include information on where to locate the constellation and the Greek mythology behind its name. 
 
## Theme Interpretation 
The theme is the night sky, including constellations and stars that can be viewed. 
 
## Intended User or Player 
The intended user is interested in learning about what constellations can be seen in the night sky at different times of the year.   It is also for those who are interested in the Greek mythology stories behind the names of these constellations. 
 
## User or Player Goal 
The main goal for the user is to navigate to a season of choice.  When one is chosen, it will link to a sub-page that will show 3 different constellations that can be seen during that season.  When a constellation is clicked, detailed information appears that will instruct them where to look in the sky to find it and a brief description of its mythological meaning.  
 
## Main Features 
The main features are on the main webpage, 4 interactive season buttons can be seen.  They are labeled “Spring”, “Summer”, “Fall”, and “Winter”.  When one is clicked, it directly links to a sub-page that has 3 individual constellation interactive buttons that when clicked activates a pop-up text box that has readable information about that constellation.  A “Play Music” is located on the main webpage, when clicked, ambient space music will play.  The “Back to the Main Menu” buttons are in the footer of each sub-page to take the user back to the main webpage. 
 
## JavaScript Features 
JavaScript features include adding the background ambient space music that is activated when the “Play Music” button is clicked.  When a user clicks on one of the 12 constellations (3 for each season) presented, an information box appears as a pop-up created through JavaScript. 
 
## Responsive Design 

Responsive design is demonstrated in my project by adjusting the size of the screen to make it smaller or when viewed on a mobile device. The individual season card containers move into a column vertically, so they can all still be seen and interacted with.  The navigation is straightforward, and the elements have clear interactive features due to the way the color changes when the cursor moves over that element.  The season names appear when the cursor moves over the individual season cards as well.  The “Back to the Main Menu” and “Play Music” buttons change color to indicate that they are interactive. 
 
## User Testing 
I had one user tester.  She gave me feedback, performed requested tasks, and answered the questions I posted.  The tasks were easily accomplished and all questions were answered. The navigation to different season pages worked well, and the readability of the website was also well done, she commented.  Buttons and elements responded to her mouse by changing color and opacity when hovered over.  This made it clear that they were interactive.  One of my questions was regarding anything being confusing.  She recommended changing the background image on the constellation sub-pages to make the constellation buttons stand out more and to make it clearer that they are interactive.  The most important recommendation was to make the images on the homepage enter a single column layout when the screen size is viewed on a mobile device. 
 
## Revisions 
I completed 3 revisions which included all the recommended changes from my user tester, and one is something I added. 

1. I changed the original layout of the main webpage.  The title was originally in the center with 2 of the seasons card containers on the left and 2 on the right.  This caused overlapping and obstruction of the title of the webpage when the screen size became smaller.  I rearranged them into a horizontal layout and removed the CSS position “absolute” from the card container command.  I added the media query “@media” with flex_ direction:column; to align items to the center.  Now my webpage vertically arranges the card containers in a column to retain their visibility and interactive functions. 

 

2. I changed the background image on all the constellation sub-pages to a different photograph.  The new background has tiny stars that do not draw too much attention away from the stars that are illustrated inside the interactive elements.  The outlines of the constellation boxes stand out now. 

 

3. I added background ambient music from a royalty free source on Pixabay.com. The music will start playing when the user clicks on the “Play Music” button at the top of the main webpage.
